# Combat and Loot Foundation Leads

Date created: 2026-05-17
Status: lead ledger only; do not build simulator yet

## Purpose

This document stores verified leads for later combat and loot simulation work. It is not a canonical game-data module and should not be used as website truth until each finding is evidence-closed and moved to the appropriate source-of-truth location.

Long-term goal: support a simulator that can estimate loot boxes gained from Wairo Dungeon and Kairo Room.

## Capture Rule

When a lead is found, record:
- Topic
- Function/class/file/table name
- Exact source path or RVA
- Evidence snippet or row identifier
- What appears to be known
- What remains unknown
- Confidence: confirmed, likely, or unclear
- Follow-up target

Do not infer game facts from names alone. If a value or relationship is not verified, leave it unlabeled.

## Lead Categories

- Damage formulas
- Attack, defense, and stat scaling
- Turn order or speed logic
- Hit, miss, and crit logic
- Skill activation logic
- Enemy or monster reward logic
- Loot and drop table logic
- Chest, reward, and multi-box handling
- Dungeon battle flow
- Party and unit targeting rules
- Battle result or reward settlement
- Functions/classes related to combat, rewards, boxes, drops, or loot
